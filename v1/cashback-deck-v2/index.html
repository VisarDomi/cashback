Innovation Pitch (for the application)

First cashback platform built on Albania's fiskalizimi fiscal infrastructure.

Every receipt in Albania already has a QR code (fiskalizimi). We turn that existing government infrastructure into a consumer cashback system — no new hardware, no merchant integration cost. Scan the receipt you already get, earn cashback automatically.

Tech stack: SvelteKit, TypeScript, Node.js, PostgreSQL — the same stack the CTO has used to build and operate 6+ applications solo for 3+ years.
